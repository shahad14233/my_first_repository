# Shahad Almutairi Portfolio

A responsive personal portfolio website for **Shahad Almutairi** based on the approved **Design 1 — Modern & Professional (Light)** direction.

## Portfolio focus
- AI, data and digital transformation profile
- Professional experience and end-to-end delivery ownership
- Featured work including Tamkeen Prioritization Engine, FURSA, Procurement Analytics, Human Capital Analytics, Shared Services SLA Analytics, Invoice AI Agent and PMO Performance Dashboard
- Clear separation between built/delivered work and assessments
- Research, education, certifications and current AI-agent learning focus

## Files
- `index.html` — portfolio home page
- `styles.css` — responsive styling
- `script.js` — navigation, filters, animations and project modals
- `cv.html` — web CV with Print / Save PDF support
- `assets/favicon.svg` — site icon
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## Run locally
Open `index.html` directly in a browser or serve the folder with any static web server.

## GitHub Pages
The repository includes a GitHub Pages workflow that deploys the static site on pushes to `main`. GitHub Pages must be allowed for the repository/account.

## Content positioning
- `Invoice AI Agent` is explicitly marked **Pre-Launch**.
- Azure AI Foundry is presented under **Currently Exploring**, not as a mastered/core skill.
- Tamkeen is positioned as the broader prioritization engine covering school priorities, rehabilitation, AC and decision-support scenarios.
- Assessment work is separated from built products to keep contribution claims accurate.
